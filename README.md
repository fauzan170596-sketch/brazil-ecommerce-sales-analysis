Brazil E-Commerce Sales Performance Analysis

End-to-End Data Analysis Project using SQL, Python, Excel, and Tableau

## About This Project

This project analyzes the sales performance of a Brazilian e-commerce platform using transactional data from the Olist dataset. The objective is to identify sales trends, customer payment behavior, top-performing product categories, and seller performance through an interactive Tableau dashboard.

The project follows an end-to-end data analysis workflow, including data understanding, cleaning, analysis, visualization, and business recommendations.

## Project Objective

This analysis answers several business questions:

How has monthly revenue changed over time?
Which product categories generate the highest revenue?
Which payment methods contribute the most revenue?
Which sellers generate the highest revenue?
What business insights can support better business decisions?

## Business Context

An e-commerce company needs a dashboard to monitor sales performance and customer purchasing behavior across multiple payment methods, product categories, and sellers.

Without a centralized dashboard, stakeholders have difficulty identifying sales trends, evaluating product performance, and making data-driven business decisions.

## Dataset Information

The analysis uses the **Olist Brazilian E-Commerce Public Dataset**, which contains transactional information from an online marketplace in Brazil.

### Main Tables Used

- Customers
- Orders
- Order Payments
- Sellers

### Data Preparation

The preparation process includes:

- Merging multiple datasets.
- Removing duplicate records.
- Handling missing values.
- Converting timestamp fields into monthly periods.
- Creating calculated fields for KPI metrics.
